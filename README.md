## Описание программы
*"Currency Converter — это графическое приложение, разработанное на языке Python. Оно предназначено для быстрой и удобной конвертации валют с использованием актуальных курсов, получаемых в реальном времени через внешний API."*
## Требования для запуска
Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install requests`
## Как запустить
```bash
git clone https://github.com/Nkirill025/GitHub-User-Finder
cd GitHub-User-Finder
python main.py
```
## Как пользоваться
1.Запуск приложения. Откроем папку с проектом и запустите файл main.py через Python.
2.Выбор валют. В выпадающих списках «Из» и «В» выберите нужные вам валюты (например, из USD в EUR).
3.Ввод суммы. Введем числовое значение суммы, которую хотите конвертировать, в поле «Сумма».
4.Конвертацияю Нажмем кнопку «Конвертировать».
5.Просмотр результата. Результат расчета мгновенно отобразится под кнопкой в формате: «Результат: [ЧИСЛО] [Целевая валюта]».
6.Просмотр истории. Операция будет автоматически добавлена в таблицу истории, расположенную в нижней части окна..
## Пример работы
Добавление записи:
1.В поле выбора «Из» пользователь выбирает USD.
2.В поле выбора «В» пользователь выбирает EUR.
3.В поле «Сумма» пользователь вводит число 250.
4.Пользователь нажимает кнопку «Конвертировать».
